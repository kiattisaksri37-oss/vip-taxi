# VIP Taxi: ระบบหลังบ้าน + แอปผู้เช่าขับ (VIP Driver)

ชุดนี้มี 3 ส่วนที่ใช้ฐานข้อมูลเดียวกันบน Firebase

| ส่วน | ไฟล์ | ใช้งานที่ |
|---|---|---|
| ระบบหลังบ้าน (พนักงาน) | `admin/index.html` | เว็บ `https://<ชื่อผู้ใช้>.github.io/<ชื่อโปรเจกต์>/` |
| แอปคนขับ Android | `driver/` | ไฟล์ APK ที่ GitHub สร้างให้ |
| แอปคนขับเวอร์ชันเว็บ (ใช้กับ iPhone) | `driver/www/index.html` | เว็บ `https://<ชื่อผู้ใช้>.github.io/<ชื่อโปรเจกต์>/driver/` |

ทำตามขั้นตอนด้านล่างครั้งเดียว ใช้เวลาประมาณ 30 นาที ไม่ต้องลงโปรแกรมในเครื่อง

---

## ขั้นที่ 1: สร้างฐานข้อมูล Firebase

1. เข้า https://console.firebase.google.com ด้วยบัญชี Google ของบริษัท
2. กด **Create a project** ตั้งชื่อ เช่น `vip-taxi` ตอนถามเรื่อง Google Analytics ให้ปิดได้
3. เมนูซ้าย **Build > Authentication** กด **Get started** แล้วเลือก **Email/Password** กดเปิด **Enable** แล้ว **Save**
4. เมนูซ้าย **Build > Firestore Database** กด **Create database**
   - Location เลือก **asia-southeast1 (Singapore)**
   - เลือก **Start in production mode**
5. ในหน้า Firestore เปิดแท็บ **Rules** ลบข้อความเดิมทั้งหมด คัดลอกเนื้อหาไฟล์ `firestore.rules` มาวาง แล้วกด **Publish**
6. กดรูปเฟือง **Project settings** > แท็บ **General** เลื่อนลงไปที่ **Your apps** กดไอคอน **</>** (Web)
   - ตั้งชื่อแอป เช่น `VIP Taxi` ไม่ต้องติ๊ก Hosting แล้วกด **Register app**
   - หน้าจอจะแสดงค่า `firebaseConfig` ให้คัดลอกค่าแต่ละบรรทัด (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId) ไปวางในไฟล์ `firebase-config.js` ของชุดนี้

## ขั้นที่ 2: ฝากไฟล์ไว้บน GitHub (ระบบจะสร้าง APK ให้เอง)

1. สมัครบัญชีที่ https://github.com (ฟรี)
2. กด **New repository** ตั้งชื่อ เช่น `vip-taxi` เลือก **Public** แล้วกด **Create repository**
   - ต้องเป็น Public จึงเปิดเว็บด้วย GitHub Pages ได้ฟรี ในโปรเจกต์มีแค่โค้ดและข้อมูลตัวอย่าง ข้อมูลจริงอยู่ใน Firebase ซึ่งป้องกันด้วยกฎในขั้นที่ 1
3. ในหน้า repository กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงไป กด **Commit changes**
4. ตรวจว่ามีไฟล์ `.github/workflows/build.yml` อยู่ในหน้า repository
   - ถ้าไม่เห็น (Mac มักไม่ลากโฟลเดอร์ที่ขึ้นต้นด้วยจุด) ให้กด **Add file > Create new file** พิมพ์ชื่อ `.github/workflows/build.yml` แล้ววางเนื้อหาไฟล์นั้นลงไป กด **Commit**
5. ไปที่ **Settings > Pages** ช่อง **Source** เลือก **GitHub Actions**
6. ไปที่แท็บ **Actions** กด workflow **Build VIP apps** แล้วกด **Run workflow** รอประมาณ 5–10 นาทีจนขึ้นเครื่องหมายถูกสีเขียว

## ขั้นที่ 3: อนุญาตเว็บของบริษัทใน Firebase

กลับไปที่ Firebase > **Authentication > Settings > Authorized domains** กด **Add domain** แล้วใส่ `<ชื่อผู้ใช้ GitHub>.github.io`

## ขั้นที่ 4: เปิดระบบหลังบ้านครั้งแรก

1. เปิด `https://<ชื่อผู้ใช้>.github.io/vip-taxi/`
2. ครั้งแรกระบบจะให้สร้าง **บัญชีเจ้าของระบบ** ใส่ชื่อ อีเมล และรหัสผ่าน
3. ไปที่ **ตั้งค่า**
   - ใส่ข้อมูลบริษัท หมายเลขพร้อมเพย์ เวลาออกบิลอัตโนมัติ และค่าปรับ
   - ถ้าต้องการข้อมูลตัวอย่าง กด **นำเข้าข้อมูลจากไฟล์ JSON** แล้วเลือก `data/initial-data.json`
   - ถ้ามีข้อมูลจริงในระบบบน Claude ให้เปิดระบบนั้น กด **ดาวน์โหลดข้อมูลทั้งหมด (JSON)** แล้วนำไฟล์นั้นมานำเข้าที่นี่
   - เพิ่มพนักงานในหัวข้อ **พนักงานที่เข้าระบบได้**: ผู้จัดการทำได้ทุกอย่าง ส่วนพนักงานเก็บเงินออกบิล รับชำระ และตรวจสลิปได้
4. ไปที่ **ทะเบียนรถและคนขับ > คนขับ** แล้วกด **เปิดบัญชีแอป** ของคนขับแต่ละคน ระบบจะแสดงเบอร์และ PIN ให้ส่งต่อให้คนขับ

## ขั้นที่ 5: ติดตั้งแอปบนมือถือคนขับ

**Android**
1. ใน GitHub แท็บ **Actions** กดรายการล่าสุดที่ขึ้นสีเขียว เลื่อนลงไปที่ **Artifacts** กด **VIP-Driver-APK** เพื่อดาวน์โหลด (ได้ไฟล์ zip ข้างในเป็น `VIP-Driver-1.0.x.apk`)
2. ส่งไฟล์ .apk ให้คนขับ เช่น ทาง LINE
3. คนขับกดเปิดไฟล์ ถ้ามือถือถามเรื่อง **ติดตั้งแอปที่ไม่รู้จัก** ให้กดอนุญาต
4. เปิดแอป **VIP Driver** ใส่เบอร์และ PIN

**iPhone**: เปิด `https://<ชื่อผู้ใช้>.github.io/vip-taxi/driver/` ใน Safari กดปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอนแอปบนหน้าจอ

## การใช้งานประจำวัน

- คนขับจ่ายเงินในแอป: เลือกบิล สแกน QR พร้อมเพย์ แนบสลิป แล้วกดส่ง
- พนักงานเปิดเมนู **คำขอจากคนขับ** ดูรูปสลิป แล้วกด **ยืนยันรับเงินและออกใบเสร็จ** ระบบจะตัดยอดบิลและออกใบเสร็จให้ทันที คนขับเห็นผลในแอปทันที
- คำขอลาหรือแจ้งรถเสีย: ผู้จัดการกดอนุมัติ ระบบจะสร้างวันงดเก็บค่าเช่าให้
- ทุกครั้งที่แก้ไฟล์ใน GitHub ระบบจะสร้าง APK เวอร์ชันใหม่และอัปเดตเว็บให้เอง

## ข้อควรรู้

- **ค่าใช้จ่าย**: Firebase แผนฟรี (Spark) อ่านข้อมูลได้วันละ 50,000 ครั้ง เขียนวันละ 20,000 ครั้ง และเก็บข้อมูลได้ 1 GB เพียงพอสำหรับคนขับหลักสิบคน รูปสลิปถูกย่อให้ประมาณ 100–200 KB ต่อรูป
- **APK ที่ได้เป็นแบบติดตั้งเอง (debug)** Android อาจขึ้นคำเตือนตอนติดตั้ง ถ้าจะลง Google Play ต้องสร้างกุญแจเซ็นแอปและบัญชีนักพัฒนา Google Play (ค่าสมัคร 25 ดอลลาร์ครั้งเดียว) แจ้งผมได้ถ้าต้องการขั้นตอนนี้
- **คนขับลืม PIN**: ผู้จัดการกด **รีเซ็ต PIN แอป** ที่หน้าคนขับ ระบบจะสร้าง PIN ใหม่และปิดบัญชีเดิม
- **การออกบิลอัตโนมัติ** ทำงานเมื่อมีพนักงานเปิดระบบหลังบ้าน ถ้าไม่มีใครเปิด ระบบจะออกบิลย้อนหลังให้ครบเมื่อเปิดครั้งถัดไป
- **ระบบเดิมบน Claude** ยังเปิดได้ แต่ข้อมูลแยกจาก Firebase เมื่อย้ายมาแล้วให้ใช้เว็บบน GitHub เป็นหลัก
- **สำรองข้อมูล**: กด **ดาวน์โหลดข้อมูลทั้งหมด (JSON)** ที่เมนูตั้งค่าเป็นประจำ เช่น ทุกสิ้นเดือน

## โครงสร้างไฟล์

```
admin/index.html              ระบบหลังบ้าน
driver/www/index.html         แอปคนขับ
driver/assets/                ไอคอนและหน้าจอเปิดแอป
driver/package.json           รายการเครื่องมือสร้างแอป (Capacitor 6)
driver/capacitor.config.json  ชื่อแอปและรหัสแอป (com.viptaxi.driver)
firebase-config.js            ค่าตั้งค่า Firebase ของบริษัท (แก้ไฟล์นี้ไฟล์เดียว)
firestore.rules               กฎความปลอดภัยของฐานข้อมูล
data/initial-data.json        ข้อมูลตัวอย่างสำหรับนำเข้า
.github/workflows/build.yml   ขั้นตอนสร้าง APK และเว็บอัตโนมัติ
```
